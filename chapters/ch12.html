    Chapter 12

    適合度與獨立性檢定

    四個可直接複製修改的 Python 模板：多項分配適合度檢定、獨立性檢定、常態性適合度檢定與 Jarque–Bera 檢定。

    先選你要哪一個

    • 觀察次數是否符合指定比例：Chi-square goodness-of-fit test。
    • 兩個類別變數是否互相獨立：Chi-square test of independence。
    • 資料是否符合常態分配：常態性適合度檢定。
    • 用偏態與峰度檢查常態性：Jarque–Bera test。

    12.1 多項分配適合度檢定

    import numpy as np
from scipy import stats

# 實際觀察次數
observed = np.array([35, 45, 20])

# H0 下的理論比例
expected_prob = np.array([0.30, 0.50, 0.20])

alpha = 0.05

total = observed.sum()
expected = total * expected_prob

chi2_stat, p_value = stats.chisquare(
    f_obs=observed,
    f_exp=expected
)

if p_value < alpha:
    decision = "拒絕 H0"
    conclusion = "觀察分布與理論分布有顯著差異。"
else:
    decision = "不拒絕 H0"
    conclusion = "沒有足夠證據認為觀察分布與理論分布不同。"

print("Observed =", observed)
print("Expected =", expected)
print("χ² =", round(chi2_stat, 4))
print("p-value =", round(p_value, 6))
print("決策：", decision)
print("結論：", conclusion)

    12.2 獨立性檢定

    import numpy as np
from scipy import stats

# 列：Group 1、Group 2
# 欄：購買、不購買
table = np.array([
    [60, 40],
    [45, 55]
])

alpha = 0.05

chi2_stat, p_value, df, expected = stats.chi2_contingency(
    table
)

if p_value < alpha:
    decision = "拒絕 H0"
    conclusion = "兩個類別變數之間有顯著關聯。"
else:
    decision = "不拒絕 H0"
    conclusion = "沒有足夠證據認為兩個類別變數有關聯。"

print("Observed Table:")
print(table)
print("\nExpected Table:")
print(np.round(expected, 2))
print("\nχ² =", round(chi2_stat, 4))
print("df =", df)
print("p-value =", round(p_value, 6))
print("決策：", decision)
print("結論：", conclusion)

    12.3 常態性適合度檢定

    import numpy as np
from scipy import stats

data = np.array([
    51, 49, 50, 52, 48,
    53, 47, 50, 51, 49,
    52, 48, 50, 51, 49
], dtype=float)

alpha = 0.05

mu = np.mean(data)
sigma = np.std(data, ddof=1)

z_data = (data - mu) / sigma

ks_stat, p_value = stats.kstest(
    z_data,
    "norm"
)

if p_value < alpha:
    decision = "拒絕 H0"
    conclusion = "資料有顯著證據顯示不符合常態分配。"
else:
    decision = "不拒絕 H0"
    conclusion = "沒有足夠證據認為資料偏離常態分配。"

print("K-S statistic =", round(ks_stat, 4))
print("p-value =", round(p_value, 6))
print("決策：", decision)
print("結論：", conclusion)
    這裡是教學用快速模板。若平均數與標準差也由同一份資料估計，嚴格來說標準 K-S 檢定的 p-value 並不是 Lilliefors 校正後的精確結果。

    12.4 Jarque–Bera 檢定

    import numpy as np
from scipy import stats

data = np.array([
    51, 49, 50, 52, 48,
    53, 47, 50, 51, 49,
    52, 48, 50, 51, 49
], dtype=float)

alpha = 0.05

result = stats.jarque_bera(data)

jb_stat = result.statistic
p_value = result.pvalue

skewness = stats.skew(data)
kurtosis = stats.kurtosis(
    data,
    fisher=False
)

if p_value < alpha:
    decision = "拒絕 H0"
    conclusion = "資料有顯著證據顯示不符合常態分配。"
else:
    decision = "不拒絕 H0"
    conclusion = "沒有足夠證據認為資料偏離常態分配。"

print("Skewness =", round(skewness, 4))
print("Kurtosis =", round(kurtosis, 4))
print("JB =", round(jb_stat, 4))
print("p-value =", round(p_value, 6))
print("決策：", decision)
print("結論：", conclusion)

    快速選擇

    • stats.chisquare()：實際次數 vs 理論比例。
    • stats.chi2_contingency()：兩個類別變數是否獨立。
    • stats.kstest()：常態性適合度快速檢查。
    • stats.jarque_bera()：用偏態與峰度檢查常態性。

    練習題

    1. 修改模型 1 的理論比例，觀察檢定結果。
    2. 修改模型 2 的列聯表，檢查兩個類別變數是否獨立。
    3. 把模型 3 的資料改成明顯右偏資料，觀察 p-value。
    4. 使用同一份資料比較 K-S 與 Jarque–Bera 的結果。

    本章重點整理

    多項分配適合度與類別變數獨立性主要使用 χ²； 常態性則可使用適合度檢定或 Jarque–Bera 檢定。
