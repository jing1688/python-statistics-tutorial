    Chapter 13

    ANOVA

    三個可以直接複製修改的 Python 模板： One-way ANOVA、Two-way ANOVA 無交互作用、Two-way ANOVA 有交互作用。

    先選你要哪一個

    • 只有一個因子：One-way ANOVA。
    • 有兩個因子，但只看各自主效果：Two-way ANOVA 無交互作用。
    • 有兩個因子，而且要檢查兩因子是否互相影響：Two-way ANOVA 有交互作用。
    ANOVA 的核心問題都是：不同組別的母體平均數是否相同。 當 p-value < alpha 時，表示至少有某些平均數存在顯著差異。

    13.1 One-way ANOVA

    適合只有一個類別因子，但有三組以上要比較平均數的情況。 例如比較三種教學方法的平均成績。 

    import numpy as np
from scipy import stats

# =========================================================
# 模型 1：One-way ANOVA
# H0: μ1 = μ2 = μ3 = ...
# =========================================================

# ---------------------------------------------------------
# 使用者設定區：只需要改這裡
# ---------------------------------------------------------

group1 = np.array([
    78, 82, 85, 80, 79
])

group2 = np.array([
    88, 90, 85, 91, 87
])

group3 = np.array([
    72, 75, 70, 74, 73
])

alpha = 0.05


# ---------------------------------------------------------
# 執行 ANOVA
# ---------------------------------------------------------

F_stat, p_value = stats.f_oneway(
    group1,
    group2,
    group3
)


# ---------------------------------------------------------
# 自動判斷
# ---------------------------------------------------------

if p_value < alpha:

    decision = "拒絕 H0"

    conclusion = (
        "至少有一組母體平均數與其他組不同。"
    )

else:

    decision = "不拒絕 H0"

    conclusion = (
        "沒有足夠證據認為各組母體平均數不同。"
    )


# ---------------------------------------------------------
# 輸出
# ---------------------------------------------------------

print("=== One-way ANOVA ===")

print(
    "Group 1 平均數 =",
    round(np.mean(group1), 4)
)

print(
    "Group 2 平均數 =",
    round(np.mean(group2), 4)
)

print(
    "Group 3 平均數 =",
    round(np.mean(group3), 4)
)

print(
    "F =",
    round(F_stat, 4)
)

print(
    "p-value =",
    round(p_value, 6)
)

print(
    "alpha =",
    alpha
)

print(
    "決策：",
    decision
)

print(
    "結論：",
    conclusion
)
    ANOVA 顯著只代表「至少有一組不同」，不會直接告訴你是哪兩組不同。 如果需要知道差異在哪裡，通常再做事後比較，例如 Tukey HSD。

    13.2 Two-way ANOVA：無交互作用

    適合有兩個類別因子，想分別檢查 Factor A 與 Factor B 是否影響結果， 但暫時不考慮兩者的交互作用。

    例如研究「教學方法」與「性別」是否影響成績。 

    import pandas as pd
import statsmodels.api as sm

from statsmodels.formula.api import ols

# =========================================================
# 模型 2：Two-way ANOVA 無交互作用
# =========================================================

# ---------------------------------------------------------
# 使用者設定區：只需要改資料
# ---------------------------------------------------------

df = pd.DataFrame({
    "score": [
        78, 82, 80,
        85, 88, 84,
        75, 77, 76,
        82, 84, 83
    ],

    "method": [
        "A", "A", "A",
        "A", "A", "A",
        "B", "B", "B",
        "B", "B", "B"
    ],

    "gender": [
        "M", "M", "M",
        "F", "F", "F",
        "M", "M", "M",
        "F", "F", "F"
    ]
})

alpha = 0.05


# ---------------------------------------------------------
# 建立模型
# 不加入 method:gender
# ---------------------------------------------------------

model = ols(
    "score ~ C(method) + C(gender)",
    data=df
).fit()


# ---------------------------------------------------------
# ANOVA Table
# ---------------------------------------------------------

anova_table = sm.stats.anova_lm(
    model,
    typ=2
)

print(
    "=== Two-way ANOVA：無交互作用 ==="
)

print(
    anova_table
)


# ---------------------------------------------------------
# 自動判斷
# ---------------------------------------------------------

p_method = anova_table.loc[
    "C(method)",
    "PR(>F)"
]

p_gender = anova_table.loc[
    "C(gender)",
    "PR(>F)"
]

print()

if p_method < alpha:
    print(
        "Method：拒絕 H0，"
        "教學方法對平均成績有顯著影響。"
    )
else:
    print(
        "Method：不拒絕 H0，"
        "沒有足夠證據認為教學方法有影響。"
    )

if p_gender < alpha:
    print(
        "Gender：拒絕 H0，"
        "性別對平均成績有顯著影響。"
    )
else:
    print(
        "Gender：不拒絕 H0，"
        "沒有足夠證據認為性別有影響。"
    )
    無交互作用模型的公式是 Y ~ C(A) + C(B)。 它只檢查 A 與 B 各自的主效果。

    13.3 Two-way ANOVA：有交互作用

    如果除了想看 Factor A 與 Factor B 的主效果， 還想知道「A 的效果是否會因 B 不同而改變」， 就要加入交互作用項。 

    import pandas as pd
import statsmodels.api as sm

from statsmodels.formula.api import ols

# =========================================================
# 模型 3：Two-way ANOVA 有交互作用
# =========================================================

# ---------------------------------------------------------
# 使用者設定區：只需要改資料
# ---------------------------------------------------------

df = pd.DataFrame({
    "score": [
        78, 82, 80,
        90, 92, 91,
        75, 77, 76,
        80, 81, 79
    ],

    "method": [
        "A", "A", "A",
        "A", "A", "A",
        "B", "B", "B",
        "B", "B", "B"
    ],

    "gender": [
        "M", "M", "M",
        "F", "F", "F",
        "M", "M", "M",
        "F", "F", "F"
    ]
})

alpha = 0.05


# ---------------------------------------------------------
# 建立模型
# C(method) * C(gender)
# 等於：
# C(method)
# + C(gender)
# + C(method):C(gender)
# ---------------------------------------------------------

model = ols(
    "score ~ C(method) * C(gender)",
    data=df
).fit()


# ---------------------------------------------------------
# ANOVA Table
# ---------------------------------------------------------

anova_table = sm.stats.anova_lm(
    model,
    typ=2
)

print(
    "=== Two-way ANOVA：有交互作用 ==="
)

print(
    anova_table
)


# ---------------------------------------------------------
# 取得 p-value
# ---------------------------------------------------------

p_method = anova_table.loc[
    "C(method)",
    "PR(>F)"
]

p_gender = anova_table.loc[
    "C(gender)",
    "PR(>F)"
]

p_interaction = anova_table.loc[
    "C(method):C(gender)",
    "PR(>F)"
]


# ---------------------------------------------------------
# 自動判斷
# ---------------------------------------------------------

print()

if p_method < alpha:
    print(
        "Method 主效果：顯著"
    )
else:
    print(
        "Method 主效果：不顯著"
    )

if p_gender < alpha:
    print(
        "Gender 主效果：顯著"
    )
else:
    print(
        "Gender 主效果：不顯著"
    )

if p_interaction < alpha:

    print(
        "Interaction：顯著"
    )

    print(
        "教學方法的效果會因性別不同而改變。"
    )

else:

    print(
        "Interaction：不顯著"
    )

    print(
        "沒有足夠證據顯示兩個因子存在交互作用。"
    )
    有交互作用的公式是 Y ~ C(A) * C(B)。
    其中 * 會同時加入 A、B 與 A:B 交互作用項。

    13.4 畫交互作用圖

    Two-way ANOVA 如果有交互作用， 最直觀的方法之一就是畫 interaction plot。 

    import matplotlib.pyplot as plt

from statsmodels.graphics.factorplots import interaction_plot

interaction_plot(
    x=df["method"],
    trace=df["gender"],
    response=df["score"]
)

plt.xlabel(
    "Teaching Method"
)

plt.ylabel(
    "Mean Score"
)

plt.title(
    "Interaction Plot"
)

plt.show()
    如果兩條線明顯不平行甚至交叉，通常代表可能存在交互作用； 最終仍以 ANOVA 表中的 interaction p-value 判斷。

    快速選擇

    • 一個因子 → stats.f_oneway()
    • 兩個因子，不考慮交互 → Y ~ C(A) + C(B)
    • 兩個因子，要檢查交互 → Y ~ C(A) * C(B)

    練習題

    1. 使用 One-way ANOVA 比較四種教學方法的平均成績。
    2. 建立一份包含「教學方法」與「性別」的資料， 執行 Two-way ANOVA 無交互作用模型。
    3. 將模型改成 C(method) * C(gender)， 檢查交互作用是否顯著。
    4. 畫出 interaction plot， 比較圖形與交互作用 p-value 的結果。

    本章重點整理

    One-way ANOVA 處理一個因子； Two-way ANOVA 處理兩個因子； 如果想檢查其中一個因子的效果是否會受到另一個因子影響， 就在模型中加入 interaction。
