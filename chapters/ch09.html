    Chapter 09

    假設檢定

    直接複製這份 Python 程式，只要修改資料、α、H₀ 與檢定方向， 即可完成單一母體平均數假設檢定。

    只需要修改這五個地方

    • data：樣本資料。
    • mu0：H₀ 中假設的母體平均數。
    • alpha：顯著水準，例如 0.05。
    • alternative：雙尾、右尾或左尾。
    • sigma：母體標準差已知時填數值；未知時填 None。

    假設檢定通用模板

    import numpy as np
from scipy import stats

# =========================================================
# 單一母體平均數假設檢定
# 只需要修改「使用者設定區」
# =========================================================

# ---------------------------------------------------------
# 1. 使用者設定區
# ---------------------------------------------------------

data = np.array([
    98, 102, 95, 100, 105,
    97, 103, 99, 101, 96
], dtype=float)

# H0: μ = mu0
mu0 = 100

# 顯著水準 alpha
alpha = 0.05

# 檢定方向
# "two-sided"：H1: μ != mu0
# "greater"  ：H1: μ > mu0
# "less"     ：H1: μ < mu0
alternative = "two-sided"

# 母體標準差
# 已知時填數值，例如 sigma = 15
# 未知時填 None，程式會自動使用 t 檢定
sigma = None


# ---------------------------------------------------------
# 2. 樣本統計量
# ---------------------------------------------------------

n = len(data)
x_bar = np.mean(data)
s = np.std(data, ddof=1)


# ---------------------------------------------------------
# 3. 執行檢定
# ---------------------------------------------------------

if sigma is None:

    # 母體標準差未知：t 檢定
    test_type = "單一樣本 t 檢定"

    result = stats.ttest_1samp(
        a=data,
        popmean=mu0,
        alternative=alternative
    )

    test_statistic = result.statistic
    p_value = result.pvalue

else:

    # 母體標準差已知：z 檢定
    test_type = "單一樣本 z 檢定"

    standard_error = sigma / np.sqrt(n)

    test_statistic = (
        x_bar - mu0
    ) / standard_error

    if alternative == "two-sided":

        p_value = 2 * (
            1 - stats.norm.cdf(
                abs(test_statistic)
            )
        )

    elif alternative == "greater":

        p_value = (
            1 - stats.norm.cdf(
                test_statistic
            )
        )

    else:

        p_value = stats.norm.cdf(
            test_statistic
        )


# ---------------------------------------------------------
# 4. 自動產生 H0、H1
# ---------------------------------------------------------

h0_text = f"H0: μ = {mu0}"

if alternative == "two-sided":
    h1_text = f"H1: μ ≠ {mu0}"

elif alternative == "greater":
    h1_text = f"H1: μ > {mu0}"

else:
    h1_text = f"H1: μ < {mu0}"


# ---------------------------------------------------------
# 5. 自動判斷結果
# ---------------------------------------------------------

if p_value < alpha:

    decision = "拒絕 H0"

    conclusion = (
        f"在顯著水準 α = {alpha} 下，"
        "有足夠證據支持 H1。"
    )

else:

    decision = "不拒絕 H0"

    conclusion = (
        f"在顯著水準 α = {alpha} 下，"
        "沒有足夠證據支持 H1。"
    )


# ---------------------------------------------------------
# 6. 輸出結果
# ---------------------------------------------------------

print("=" * 45)
print("假設檢定結果")
print("=" * 45)

print("檢定方法：", test_type)
print(h0_text)
print(h1_text)

print("-" * 45)

print("樣本數 n =", n)
print("樣本平均數 =", round(x_bar, 4))
print("樣本標準差 =", round(s, 4))
print("檢定統計量 =", round(test_statistic, 4))
print("p-value =", round(p_value, 6))

print("-" * 45)

print("決策：", decision)
print("結論：", conclusion)

print("=" * 45)

    三種檢定方向

    雙尾檢定

    # H0: μ = 100
# H1: μ != 100

mu0 = 100
alpha = 0.05
alternative = "two-sided"

    右尾檢定

    # H0: μ = 100
# H1: μ > 100

mu0 = 100
alpha = 0.05
alternative = "greater"

    左尾檢定

    # H0: μ = 100
# H1: μ < 100

mu0 = 100
alpha = 0.05
alternative = "less"

    切換 z 檢定與 t 檢定

    t 檢定

    # 母體標準差未知
sigma = None

    z 檢定

    # 母體標準差已知，例如 σ = 15
sigma = 15
    程式會自動判斷： sigma = None 時使用 t 檢定； 填入母體標準差時使用 z 檢定。

    結果怎麼看

    • p-value < alpha：拒絕 H₀。
    • p-value ≥ alpha：不拒絕 H₀。
    統計上的標準用詞是「不拒絕 H₀」，而不是「接受 H₀」。

    練習題

    1. 將 mu0 改成 98，執行雙尾檢定。
    2. 將 alternative 改成 "greater"。
    3. 將 alpha 從 0.05 改成 0.01。
    4. 分別設定 sigma = None 與 sigma = 15，比較結果。

    本章重點整理

    • 修改 mu0 即可設定 H₀。
    • 修改 alpha 即可設定顯著水準。
    • 修改 alternative 即可切換雙尾、右尾與左尾。
    • sigma = None 時使用 t 檢定。
    • 填入 sigma 時使用 z 檢定。
    • 當 p-value < alpha 時拒絕 H₀。
