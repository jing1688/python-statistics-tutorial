    Chapter 10

    兩組比較

    三個可以直接複製修改的 Python 模板：獨立兩樣本 t 檢定、配對 t 檢定、兩母體比例 z 檢定。

    先選你要哪一個

    • 兩群不同的人／物件，比平均數：獨立兩樣本 t 檢定。
    • 同一批對象前後比較／一對一配對，比平均差：配對 t 檢定。
    • 兩群不同的人／物件，比成功率或比例：兩母體比例 z 檢定。
    三個模板都只需要修改最上方的「使用者設定區」。
    alternative = "two-sided" 為雙尾； "greater" 為右尾； "less" 為左尾。

    10.1 獨立兩樣本 t 檢定

    適合比較兩個互相獨立群體的平均數，例如 A 班與 B 班平均成績。 模板預設使用 Welch's t-test，因此不強制假設兩組母體變異數相等。 

    import numpy as np
from scipy import stats

# =========================================================
# 模型 1：獨立兩樣本 t 檢定
# H0: μ1 - μ2 = 0
# =========================================================

# ---------------------------------------------------------
# 使用者設定區：只需要改這裡
# ---------------------------------------------------------

group1 = np.array([80, 82, 78, 90, 85], dtype=float)
group2 = np.array([75, 77, 72, 80, 79], dtype=float)

alpha = 0.05

# "two-sided"：H1: μ1 != μ2
# "greater"  ：H1: μ1 > μ2
# "less"     ：H1: μ1 < μ2
alternative = "two-sided"


# ---------------------------------------------------------
# 執行檢定
# ---------------------------------------------------------

result = stats.ttest_ind(
    group1,
    group2,
    equal_var=False,
    alternative=alternative
)

t_stat = result.statistic
p_value = result.pvalue

mean1 = np.mean(group1)
mean2 = np.mean(group2)


# ---------------------------------------------------------
# 自動產生假設
# ---------------------------------------------------------

h0 = "H0: μ1 - μ2 = 0"

if alternative == "two-sided":
    h1 = "H1: μ1 - μ2 ≠ 0"
elif alternative == "greater":
    h1 = "H1: μ1 - μ2 > 0"
else:
    h1 = "H1: μ1 - μ2 < 0"


# ---------------------------------------------------------
# 自動判斷
# ---------------------------------------------------------

if p_value < alpha:
    decision = "拒絕 H0"
    conclusion = "有足夠證據支持 H1。"
else:
    decision = "不拒絕 H0"
    conclusion = "沒有足夠證據支持 H1。"


# ---------------------------------------------------------
# 輸出
# ---------------------------------------------------------

print("=== 獨立兩樣本 t 檢定 ===")
print(h0)
print(h1)
print("Group 1 平均數 =", round(mean1, 4))
print("Group 2 平均數 =", round(mean2, 4))
print("平均數差 =", round(mean1 - mean2, 4))
print("t =", round(t_stat, 4))
print("p-value =", round(p_value, 6))
print("alpha =", alpha)
print("決策：", decision)
print("結論：", conclusion)

    10.2 配對 t 檢定

    適合同一批對象的前後測，或資料具有一對一配對關係的情況。 例如同一批學生上課前與上課後的成績。 

    import numpy as np
from scipy import stats

# =========================================================
# 模型 2：配對 t 檢定
# 定義差值 d = after - before
# H0: μd = 0
# =========================================================

# ---------------------------------------------------------
# 使用者設定區：只需要改這裡
# ---------------------------------------------------------

before = np.array([70, 68, 75, 80, 72], dtype=float)
after  = np.array([75, 72, 78, 85, 76], dtype=float)

alpha = 0.05

# 注意：本模板的差值定義為 after - before
#
# "two-sided"：H1: μd != 0
# "greater"  ：H1: μd > 0，也就是 after > before
# "less"     ：H1: μd < 0，也就是 after < before
alternative = "two-sided"


# ---------------------------------------------------------
# 執行檢定
# ---------------------------------------------------------

if len(before) != len(after):
    raise ValueError("配對資料的 before 與 after 筆數必須相同。")

# scipy 的 ttest_rel(a, b) 檢定的是 mean(a - b)
# 因此放入 after, before，讓差值方向為 after - before
result = stats.ttest_rel(
    after,
    before,
    alternative=alternative
)

t_stat = result.statistic
p_value = result.pvalue

difference = after - before
mean_difference = np.mean(difference)


# ---------------------------------------------------------
# 自動產生假設
# ---------------------------------------------------------

h0 = "H0: μd = 0"

if alternative == "two-sided":
    h1 = "H1: μd ≠ 0"
elif alternative == "greater":
    h1 = "H1: μd > 0"
else:
    h1 = "H1: μd < 0"


# ---------------------------------------------------------
# 自動判斷
# ---------------------------------------------------------

if p_value < alpha:
    decision = "拒絕 H0"
    conclusion = "有足夠證據支持 H1。"
else:
    decision = "不拒絕 H0"
    conclusion = "沒有足夠證據支持 H1。"


# ---------------------------------------------------------
# 輸出
# ---------------------------------------------------------

print("=== 配對 t 檢定 ===")
print("差值定義：after - before")
print(h0)
print(h1)
print("Before 平均數 =", round(np.mean(before), 4))
print("After 平均數 =", round(np.mean(after), 4))
print("平均差 =", round(mean_difference, 4))
print("t =", round(t_stat, 4))
print("p-value =", round(p_value, 6))
print("alpha =", alpha)
print("決策：", decision)
print("結論：", conclusion)
    配對檢定最容易出錯的是「方向」。這份模板固定定義 d = after - before，所以若要檢查「後測是否高於前測」， 使用 alternative = "greater"。

    10.3 兩母體比例 z 檢定

    適合比較兩個獨立群體的比例，例如 A 方案與 B 方案的購買率、成功率或支持率。 

    import numpy as np
from statsmodels.stats.proportion import proportions_ztest

# =========================================================
# 模型 3：兩母體比例 z 檢定
# H0: p1 - p2 = 0
# =========================================================

# ---------------------------------------------------------
# 使用者設定區：只需要改這裡
# ---------------------------------------------------------

# Group 1：100 人中有 60 人成功
success1 = 60
n1 = 100

# Group 2：100 人中有 50 人成功
success2 = 50
n2 = 100

alpha = 0.05

# "two-sided"：H1: p1 != p2
# "larger"   ：H1: p1 > p2
# "smaller"  ：H1: p1 < p2
alternative = "two-sided"


# ---------------------------------------------------------
# 執行檢定
# ---------------------------------------------------------

success = np.array([
    success1,
    success2
])

n = np.array([
    n1,
    n2
])

z_stat, p_value = proportions_ztest(
    count=success,
    nobs=n,
    alternative=alternative
)

p1_hat = success1 / n1
p2_hat = success2 / n2


# ---------------------------------------------------------
# 自動產生假設
# ---------------------------------------------------------

h0 = "H0: p1 - p2 = 0"

if alternative == "two-sided":
    h1 = "H1: p1 - p2 ≠ 0"
elif alternative == "larger":
    h1 = "H1: p1 - p2 > 0"
else:
    h1 = "H1: p1 - p2 < 0"


# ---------------------------------------------------------
# 自動判斷
# ---------------------------------------------------------

if p_value < alpha:
    decision = "拒絕 H0"
    conclusion = "有足夠證據支持 H1。"
else:
    decision = "不拒絕 H0"
    conclusion = "沒有足夠證據支持 H1。"


# ---------------------------------------------------------
# 輸出
# ---------------------------------------------------------

print("=== 兩母體比例 z 檢定 ===")
print(h0)
print(h1)
print("Group 1 樣本比例 =", round(p1_hat, 4))
print("Group 2 樣本比例 =", round(p2_hat, 4))
print("比例差 =", round(p1_hat - p2_hat, 4))
print("z =", round(z_stat, 4))
print("p-value =", round(p_value, 6))
print("alpha =", alpha)
print("決策：", decision)
print("結論：", conclusion)
    注意：statsmodels 在比例檢定中的單尾名稱是 "larger" 與 "smaller"， 和 SciPy t 檢定使用的 "greater"、 "less" 不同。

    快速選擇

    • 不同兩組 + 比平均數 → stats.ttest_ind()
    • 同一批前後 + 比平均數 → stats.ttest_rel()
    • 不同兩組 + 比比例 → proportions_ztest()

    練習題

    1. 使用模型 1 比較兩班學生的平均成績是否不同。
    2. 使用模型 2 檢定後測成績是否顯著高於前測。
    3. 使用模型 3 檢定 A 方案的成功率是否高於 B 方案。
    4. 將 alpha 從 0.05 改成 0.01，觀察結論是否改變。

    本章重點整理

    • 兩個獨立群體比較平均數：獨立兩樣本 t 檢定。
    • 同一批對象前後比較：配對 t 檢定。
    • 兩個獨立群體比較比例：兩母體比例 z 檢定。
    • 三個模板都可以修改 alpha 與 alternative。
    • 當 p-value < alpha 時拒絕 H₀。
